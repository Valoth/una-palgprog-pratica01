# Explorando a Sintaxe: Algoritmos com Portugol

Este repositório marca a transição dos fluxogramas para a escrita de código estruturado. Utilizando a linguagem **Portugol**, os exercícios aqui presentes focam na manipulação de variáveis, entrada e saída de dados (I/O) e na construção de scripts interativos.

## Exercícios de Fixação

### 1. Olá Mundo Clássico
O primeiro passo em qualquer linguagem. Um script simples para validar a estrutura básica do programa e a função de saída de dados.

### 2. Coleta de Dados Cadastrais
Um algoritmo interativo que solicita informações básicas ao usuário (Nome e Idade) e as retorna de forma organizada no console. 
* **Conceitos:** Declaração de variáveis (`cadeia`, `inteiro`) e concatenação de strings.

### 3. Ficha Acadêmica Completa
Uma expansão do algoritmo anterior, incluindo dados de localização e estudo. O script simula um formulário de cadastro estudantil, tratando múltiplos tipos de dados simultaneamente.
* **Diferencial:** Organização de saída com quebras de linha (`\n`) para melhor legibilidade no terminal.

## Ferramentas e Tecnologias
* **Portugol Studio** (ou interpretador compatível)
* **Lógica de Programação Estruturada**
* **Git/GitHub** para controle de versão

## Estrutura do Código
Os arquivos `.por` seguem a estrutura padrão:
1. **Declaração de variáveis:** Espaço reservado para tipagem de dados.
2. **Função Início:** Onde a execução principal acontece.
3. **Interação:** Comandos `escreva()` para comunicar e `leia()` para captar dados do usuário.
